Interfaces
  • /<dataset>/mcp MCP, one dataset One tool, glossql, taking statements. An agent loads, annotates and queries the dataset here; every call opens on it, and the skills are served as resources.
  • /mcp MCP, the whole workspace The same tool over the whole workspace: declare sources and create datasets here; USE picks the dataset on every call.
  • /<dataset>/query query endpoint POST a query as the body, get an Arrow IPC stream back: no row cap, straight from the engine. pyarrow reads it directly.
  • /<dataset>/app the console The dataset's page is the console: the questions the agent could not settle wait for your review, beside its metrics, quality and lineage, and every table and view as a file under Export. The apps written over the dataset are in the bar's picker.
